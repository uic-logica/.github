# LOGICA @ UIC — org defaults

This repo holds org-wide defaults (issue templates, PR template, contributing guide, code of conduct). GitHub automatically applies these to any repo in the `uic-logica` org that doesn't define its own.

Actual project code lives in [`frontend`](https://github.com/uic-logica/frontend) and [`backend`](https://github.com/uic-logica/backend).
