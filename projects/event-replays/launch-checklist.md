# Event replays in 3D — launch checklist

> **Owner:** [@nicolasrufino](https://github.com/nicolasrufino) · **Last reviewed:** Sep 29, 2026 · **Audience:** Event replays team · **Type:** Checklist

Every box is checked before the public release. Owner: the team; sign-off: the lead.

- [ ] Design doc matches what shipped
- [ ] Milestone issues closed or moved; CI green on `main`
- [ ] Code freeze respected (only fixes after the freeze date)
- [ ] Internal preview: ≥ 3 members for ≥ 2 days; bugs triaged
- [ ] Privacy: personal data listed (what, where, who reads it); a delete path exists
- [ ] Security: no secrets in the repo; auth checked on the server; tokens scoped
- [ ] Dependencies and licenses reviewed
- [ ] Rollback plan: previous deploy or tag known
- [ ] Accessibility: keyboard, contrast, alt text
- [ ] README, demo writeup and screenshots updated
- [ ] GitHub Release tagged with notes
- [ ] Announced on Discord and LinkedIn
