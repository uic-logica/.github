# Additions & suggestions

The [ROADMAP.md](../ROADMAP.md) Additions list is a starting menu, not a mandate. If you've got an idea for something else worth building — a different page, tool, or feature that fits LOGICA's structure and vision but isn't already listed — you're free to build it. The only real ask is that you tell us, so nobody duplicates work by accident and the team knows what's in flight.

The point of LOGICA @ UIC isn't to enforce one person's ideology or one fixed list on everyone. It's a shared structure — the workflow in [CONTRIBUTING.md](../CONTRIBUTING.md), the roles in [docs/roles](../docs/roles) — for people to collaborate under while still bringing their own vision.

## How to add yours

1. Write a short `.md` file in this folder (`additions/your-idea.md`) covering:
   - **What** you want to build
   - **Why** it's worth building
   - Roughly **how** — stack, rough scope, doesn't need to be exact
2. PR it in against `main`, same as any other change (see [CONTRIBUTING.md](../CONTRIBUTING.md)).
3. Once it's merged, file a normal tracking issue on whichever repo it actually touches (`frontend` or `backend`), labeled `roadmap` + `enhancement` like anything else in the tracker — that issue is what gets it built and tracked day to day.

No approval gate to clear before starting. This is about visibility, not permission — the one constraint is that it fits under LOGICA's shared workflow and vision rather than going around them.
